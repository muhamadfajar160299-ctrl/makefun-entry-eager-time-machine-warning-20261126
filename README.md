# Funniest Time Machine Warning Label

A single warning label for a time machine, written to get the biggest laugh:
a lost-property notice where your future self has already claimed your stuff —
and looks terrible in your jacket.

## How it works

`main.py` (Python standard library only, deterministic, no network) writes the
one-line warning label to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
